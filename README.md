## 🎯 Цель
Освоение работы с двумерными массивами (матрицами) в языке C++, обучение обработке строк матрицы и поиску экстремумов с использованием циклов и условных операторов.

## 📝 Описание
Задана целочисленная квадратная матрица **N × N**. Необходимо для **каждой строки** матрицы определить:
1. **Количество положительных элементов** в строке.
2. **Наибольший из положительных элементов** строки (если такие существуют).

Исходная матрица выводится на экран в общепринятом виде (таблицей), а результаты обработки — в произвольной, но читаемой форме.
